# TwistyFinder

Find the twisty roads near you. A free, community-driven site for motorcycle riders: open it, and see the best-rated twisties around you, string several together into a route, and hand it off to Google Maps, Apple Maps, or Waze.

Website first, mobile app later. Non-monetized and crowd-funded.

## Status

Pre-code: discovery and design. See [docs/discovery.md](docs/discovery.md).

## Planned features

- **Near me:** location-first ranked list of nearby twisty roads, no map hunting.
- **Route planning:** multi-stop routes with export to Google Maps / Apple Maps / Waze / GPX.
- **Community:** accounts, comments, votes, road suggestions, private friend groups.
- **Smarter detection:** curvature scoring from OpenStreetMap that filters out neighborhood and subdivision streets.
